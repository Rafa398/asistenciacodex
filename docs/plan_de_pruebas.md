## 5) Pruebas mínimas por lenguaje
- **Python:** ejecución de `main.py` y validación de entrada/salida básica.
- **C:** compilación, ejecución y manejo de entrada inválida.
- **Bash:** ejecución del script y validación de parámetros.
- **ARM64 Assembly:** ensamblado/ejecución mínima y salida esperada simple.

> No se requiere framework de testing. Puedes documentar pruebas manuales con comandos y resultados.

## 6) Criterios para considerar la práctica terminada
- El flujo principal funciona.
- Existe manejo básico de errores.
- La documentación está completa y clara.
- El proyecto se puede ejecutar localmente con instrucciones simples.
