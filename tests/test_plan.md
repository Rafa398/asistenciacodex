# Checklist Breve de Validación

## 1) Checklist de pruebas mínimas
- [ ] El programa corre en terminal.
- [ ] El flujo principal produce el resultado esperado.
- [ ] Se probó al menos una entrada inválida.
- [ ] Se documentaron resultados obtenidos.

## 2) Checklist de documentación
- [ ] `docs/propuesta.md` está completo.
- [ ] `docs/caso_de_uso.md` está completo.
- [ ] `docs/plan_de_pruebas.md` tiene casos de prueba llenados.
- [ ] El `README.md` refleja la idea final del proyecto.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` funciona o está adaptado al lenguaje elegido.
- [ ] Existe `src/main.<ext>` coherente con el lenguaje seleccionado.
- [ ] Se incluyeron instrucciones claras para correr el proyecto.

## 4) Checklist de entrega final
- [ ] El alcance se mantiene pequeño y viable.
- [ ] No se usaron frameworks ni servicios externos.
- [ ] El repositorio está ordenado y entendible.
- [ ] La propuesta está lista para revisión en GitHub Classroom.
